체크한 탭은 관리자 외 사용자가 내용을 수정할 수 없습니다. 상세보기는 가능하지만 저장은 막습니다.

관리자 갱신

아래 작업은 화면을 열 때 자동 실행하지 않습니다. 데이터 원본을 바꿨거나 일지데이터에 다시 반영해야 할 때만 직접 실행하세요.
연도 이월 정리
24~26년 종사자/비종사자 중복과 이월 데이터를 정리합니다.
연가 병합
연가 원본을 종사자 현황 출결 데이터에 반영합니다.
종사자 출결 자동 생성
연가를 제외한 평일을 출석으로 다시 채웁니다.
비종사자 시작/종료일 갱신
출결 데이터 기준으로 비종사자 활동 시작일과 종료일을 갱신합니다.
시니어 출결 자동 생성
시작일/종료일 기준으로 월 20일 출결을 다시 만듭니다.
일지데이터 반영
종사자 수, 교사/공익/기타 수, 출근 명단을 24~26년 일지데이터에 다시 반영합니다.
아직 실행한 작업이 없습니다.
