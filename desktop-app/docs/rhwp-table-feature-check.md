# RHWP 표 기능 점검 기록

이 파일은 RHWP 표 기능을 수정할 때마다 반드시 갱신한다.

## 업데이트 규칙

- 표 기능을 수정하면 작업 완료 전에 이 파일을 갱신한다.
- 갱신 시각은 `yyyy-MM-dd HH:mm:ss +09:00` 형식으로 남긴다.
- 표 기능 점검 결과는 `정상`, `부분 정상`, `미해결`, `보류` 중 하나로 기록한다.
- 브라우저에서 직접 확인한 내용과 아직 확인하지 못한 내용을 분리해서 적는다.

## 기본 점검 항목

| 항목 | 확인 내용 |
| --- | --- |
| 표 클릭 | 표 셀 안쪽 클릭 시 커서가 셀 내부로 들어가는지 확인 |
| 표 메뉴 | 표 메뉴가 비활성화되지 않고 열리는지 확인 |
| 셀 속성 | 셀 속성 메뉴가 활성화되는지 확인 |
| 행 추가 | 위/아래 행 추가 메뉴가 활성화되는지 확인 |
| 열 추가 | 왼쪽/오른쪽 열 추가 메뉴가 활성화되는지 확인 |
| 표 선택 | 표 전체 선택과 셀 선택이 충돌하지 않는지 확인 |
| 표 이동 | 표가 편집 용지 여백 밖으로 밀리지 않는지 확인 |
| 표 크기 | 표 너비/높이 조절이 문서 영역 안에서 동작하는지 확인 |
